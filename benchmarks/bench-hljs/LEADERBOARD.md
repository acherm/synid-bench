# Leaderboard — bench-hljs

Generated by `python3 tools/leaderboard.py` · benchmark `bench-hljs/1`, 191 cases ([README](README.md)). Ranked by accuracy, then precision of language answers. Tag columns: right / cases carrying that tag, over all tiers (see the README).

**What it is.** highlight.js' auto-detection test files, one or a few per language, without names — 191 cases (snippet), 185 languages · labels: highlight.js' maintainers (the test's directory, a language id), crosswalked to Linguist's names · file names: none · sampling: curated (every auto-detection test file of a language) · source: https://github.com/highlightjs/highlight.js@fc3f06392f189354eed922973635ab9e9268b983. **Strengths.** content only: no file name, so every identifier is tested on the bytes; 185 languages, one file each: no language dominates; independent of Linguist: no file is a Linguist sample. **Weaknesses.** highlight.js' home turf: from 2014 to March 2024 its test suite required auto-detection to get every file right; short snippets written to show off a grammar, not files from real projects; one file per language: a per-language figure is a single file.

**How to read.** Every entry answers, for each file, the language it is written in. A case is right when the answer is exactly one language and an accepted one; *no answer / undecided* means the entry abstained or returned several candidates; `Text` means it called a source file plain text. Each benchmark's README says where its labels come from (bench-hljs: highlight.js' maintainers (the test's directory, a language id), crosswalked to Linguist's names). **Kinds:** *Synid* — a version of Synid, the CodeCommons syntax-identification tool, in its default configuration or with one strategy turned off (a setting of Synid's configuration file); *other identifier* — another tool, as a reference point; *specialised rules* — rules written for one benchmark's problem only, a ceiling for what targeted rules achieve rather than a general identifier; *lightweight LLM* — a small, cheap model asked the language (not used to build the ground truth); *candidates + lightweight LLM* — the languages PL-ultimate-llm associates with the file's extension, among which the model chooses (a broad list when none fits).
