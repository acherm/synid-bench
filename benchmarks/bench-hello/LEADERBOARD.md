# Leaderboard — bench-hello

Generated by `python3 tools/leaderboard.py` · benchmark `bench-hello/1`, 1009 cases ([README](README.md) · [history of Synid versions](HISTORY.md)). Ranked by accuracy, then precision of language answers. Tag columns: right / cases carrying that tag, over all tiers (see the README).

**What it is.** hello-world programs, one per language (leachim6/hello-world), 1,002 labels — 1009 cases (tiny program), 965 languages · labels: the contributor (the language the file is named after) · file names: real · sampling: all · source: https://github.com/leachim6/hello-world@a152253. **Strengths.** the longest tail: 1,002 labels, esoteric languages included; extensions chosen by contributors, sometimes another language's (Pebble.c): 186 cases test what a tool does when the extension lies; tiny: what a tool knows of a language's surface. **Weaknesses.** a line or two (median 2 non-blank lines); 109 cases share their bytes with another language's program; labels are file names: frameworks, platforms and jokes count as languages (52 labels tagged not-a-language); 704 of 1,009 cases in languages Linguist does not know; 13 files are not text (images, archives, an executable).

**How to read.** Every entry answers, for each file, the language it is written in. A case is right when the answer is exactly one language and an accepted one; *no answer / undecided* means the entry abstained or returned several candidates; `Text` means it called a source file plain text. Each benchmark's README says where its labels come from (bench-hello: the contributor (the language the file is named after)). **Kinds:** *Synid* — a version of Synid, the CodeCommons syntax-identification tool, in its default configuration or with one strategy turned off (a setting of Synid's configuration file); *other identifier* — another tool, as a reference point; *specialised rules* — rules written for one benchmark's problem only, a ceiling for what targeted rules achieve rather than a general identifier; *lightweight LLM* — a small, cheap model asked the language (not used to build the ground truth); *candidates + lightweight LLM* — the languages PL-ultimate-llm associates with the file's extension, among which the model chooses (a broad list when none fits).
