# Leaderboard — bench-rpgle

Generated by `python3 tools/leaderboard.py` · benchmark `bench-rpgle/1`, 760 cases ([README](README.md)). Ranked by accuracy, then precision of language answers. Tag columns: right / cases carrying that tag, over all tiers (see the README); *weighted to the population* re-weights the stratified draw to the population it was drawn from.

**What it is.** archived .rpgle files: ILE RPG in its three source formats, and the few that are not RPG — 760 cases (whole file), 4 languages · labels: an LLM judge (Claude Sonnet 4.6), the study's rules beside it · file names: real · sampling: population-sampled with weights (uniform by-file sample, files judged after the rules froze) · source: Software Heritage, via PL-ultimate-llm's .rpgle study (swh-evidence-v1@274fa4cc8). **Strengths.** drawn uniformly from the archive's 13,002 .rpgle files, with population weights; real file names and repositories (qualified SWHIDs); a legacy language no other benchmark covers, in its three source formats (tags); held out from the study's rules. **Weaknesses.** labels by one LLM judge, which saw the rules' indicators; no human check; 755 of 760 are RPGLE: the file name alone scores 99 %; one extension; three parser repositories hold a fifth of the files; the cascade's candidates include what the study observed.

**How to read.** Every entry answers, for each file, the language it is written in. A case is right when the answer is exactly one language and an accepted one; *no answer / undecided* means the entry abstained or returned several candidates; `Text` means it called a source file plain text. Each benchmark's README says where its labels come from (bench-rpgle: an LLM judge (Claude Sonnet 4.6), the study's rules beside it). **Kinds:** *Synid* — a version of Synid, the CodeCommons syntax-identification tool, in its default configuration or with one strategy turned off (a setting of Synid's configuration file); *other identifier* — another tool, as a reference point; *specialised rules* — rules written for one benchmark's problem only, a ceiling for what targeted rules achieve rather than a general identifier; *lightweight LLM* — a small, cheap model asked the language (not used to build the ground truth); *candidates + lightweight LLM* — the languages PL-ultimate-llm associates with the file's extension, among which the model chooses (a broad list when none fits).
