## `Text` by default from the Pygments step (the classifier would be right) — 307 file(s)

**Mechanism.** No heuristic decides between the extension's candidates; the Pygments-heuristics strategy then returns its starting value `Text`, which is final — the Bayesian classifier, which comes after it, never runs. The mechanism of bench-m's 10 MATLAB failures, here across hundreds of files and languages.

**Verified.** Synid with `pygmentsheuristics` disabled answers the expected language on these files.

**Suggested fix.** when no candidate's heuristic scores, return the candidates unchanged instead of `Text` (or run the classifier first) — but see the precision trade-off in the README.
