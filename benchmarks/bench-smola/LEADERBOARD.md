# Leaderboard — bench-smola

Generated by `python3 tools/leaderboard.py` · benchmark `bench-smola/1`, 3872 cases ([README](README.md) · [history of Synid versions](HISTORY.md)). Ranked by accuracy on the 1107 cases of the *gold* tier (the other tiers' labels are less sure: see the README; *all tiers* counts every case), then precision of language answers. Tag columns: right / cases carrying that tag, over all tiers (see the README).

**What it is.** files from GitHub repositories, the samples of smola/language-dataset (2019–2022), 261 languages — 3872 cases (whole file), 261 languages · labels: a human for 1,107 files (gold); for 2,765, the dataset's vote, i.e. Linguist's own answer of 2019–2022 (silver) · file names: real · sampling: all (every sample with a language label; one file per repository, ~20 per language, picked where Linguist named the language) · source: https://github.com/smola/language-dataset@4d1827d. **Strengths.** real files from 3,872 different repositories, under their real names; 1,107 labels checked by a human, of which 167 correct Linguist's answer (tag `human-overrode-linguist`); a different source from bench-linguist: only 3 files are Linguist samples. **Weaknesses.** the silver labels (2,765 files) are Linguist's own answers: circular for the Linguist family (and Synid, built from it) — read the gold tier; every sample was picked because Linguist (via GitHub's language search and a Linguist scan) named its language: files Linguist finds hard are under-represented, even in the gold tier; one human annotator for nearly all gold labels; no agreement measure; 175 samples whose label is `Unknown` (or contested) are not scored.

**How to read.** Every entry answers, for each file, the language it is written in. A case is right when the answer is exactly one language and an accepted one; *no answer / undecided* means the entry abstained or returned several candidates; `Text` means it called a source file plain text. Each benchmark's README says where its labels come from (bench-smola: a human for 1,107 files (gold); for 2,765, the dataset's vote, i.e. Linguist's own answer of 2019–2022 (silver)). **Kinds:** *Synid* — a version of Synid, the CodeCommons syntax-identification tool, in its default configuration or with one strategy turned off (a setting of Synid's configuration file); *other identifier* — another tool, as a reference point; *specialised rules* — rules written for one benchmark's problem only, a ceiling for what targeted rules achieve rather than a general identifier; *lightweight LLM* — a small, cheap model asked the language (not used to build the ground truth); *candidates + lightweight LLM* — the languages PL-ultimate-llm associates with the file's extension, among which the model chooses (a broad list when none fits).
